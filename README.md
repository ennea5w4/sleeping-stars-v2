# Sleeping Stars v2

Rainy Museによる、心にひびく言葉を星として集める静かな自己理解体験です。

## Languages

- 日本語：トップページ
- English：`/en/`
- 한국어：`/ko/`

## Accepted specification

- 8 STAR FIELD、各画面1〜3語選択
- 各フィールド6点、総得点48点
- 同点判定：合計点 → 単独選択回数 → Field 7・8 → 最後の一星
- Type 1〜9共通の正式Quiet Linesデータ
- 日本語・英語・韓国語共通ロジック
- 待ち受け版・シェア版保存画像
- 流れ星と色付き背景星座は、結果星座とは分離した背景演出

現行版Sleeping Starsとは別リポジトリで管理します。
