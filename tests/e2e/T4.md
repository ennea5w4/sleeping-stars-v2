# T4：日本語・英語・韓国語の比較

## 実行

依存環境はT3と共通です。`README.md` の手順でチェックアウト外に
Playwright core 1.65.0を用意し、システムChromiumを指定してください。

リポジトリのルートで実行します。

```sh
# 内部指標の言語別比較（42テスト）
node --test tests/locales-unit.test.cjs

# 実HTMLによる3言語比較（53テスト）
SS_E2E_RUNTIME=/tmp/sleeping-stars-t3-runtime \
SS_E2E_BROWSER=/usr/bin/chromium \
node --test tests/e2e/locales.test.cjs

# T1・T2（68件）とT3（20件）の回帰確認
SS_E2E_RUNTIME=/tmp/sleeping-stars-t3-runtime \
SS_E2E_BROWSER=/usr/bin/chromium \
node --test tests/scoring.test.cjs tests/e2e/ja.test.cjs
```

ブラウザ起動失敗・資材不足をSKIPやPASSに変換しません。
今回の検証環境はNode.js v24.22.1、Chromium 156.0.8078.79、Linux headlessです。
T4は1280×900、各言語に対応するブラウザlocale、新しいコンテキストで実行します。
既存CSSの `prefers-reduced-motion` 対応を使ってアニメーションを抑えます。
T3の20件は従来の設定で再実行します。

## ケースと件数

同じ回答データをUnitとブラウザで共有し、3言語で実行します。
`locales-cases.cjs` の期待値はリテラル、およびT1・T2の既存固定fixtureです。
本体の配点計算を期待値生成に複製しません。

| 回答 | 各言語のUnit件数 | 各言語のブラウザ件数 | 期待する結果 |
| --- | ---: | ---: | --- |
| Type 1〜9を8問単独選択 | 9 | 9 | 各タイプ `(48,8,12)`。主タイプは選択タイプ。併記はType 1、主がType 1の場合だけType 2 |
| solo優先の固定回答 | 1 | 1 | Type 3 / 併記Type 2 |
| focus優先の固定回答 | 1 | 1 | Type 5 / 併記Type 1 |
| score優先の固定回答 | 1 | 1 | 候補Type 1・2・3から1を選択し、併記Type 2 |
| 2者同点 | 1 | 2 | Type 1・2の全候補を別々に選択 |
| 3者同点 | 1 | 3 | Type 1・2・3の全候補を別々に選択 |
| 計 | 14 | 17 | 3言語合計Unit 42件、言語別ブラウザ51件 |

このほかブラウザテストファイルに、配信資材の安全性確認1件と
全17ケースの3言語結果を直接比較する1件があります。ブラウザ合計は53件です。
候補と最終タイプを表示から読み取った比較結果はメモリ上だけに保持します。
比較前に全ケースの完了数を確認するため、ケース欠落を一致扱いしません。

## 確認範囲

- `/`、`/en/`、`/ko/` の実HTMLを、内容を変えずに配信します。
- 全言語・全8問の全9語を、固定の表示位置表と照合します。
- 各Type 1〜9の8問単独選択で、表示位置から最終タイプへの対応も検証します。
- 各ページのlang・title・description、導入文・開始ボタン・導入画像を確認します。
- 設問タイトル、案内、Next・Back、9語の内容と表示、選択状態を確認します。
- 同点画面のタイトル、説明、候補文・順序と、候補全員からの結果遷移を確認します。
- 結果名・4つの説明文・見出し・選択語・併記文・保存ボタン・物語リンク・再スタートを確認します。
- 各言語の結果キャラクター画像が正常に読み込まれることを確認します。
- 既存仕様で非表示になる英語・韓国語の有料導線と読み仮名は、欠落と判定しません。
- 表示対象の文言は空でないこと、可視状態、要素サイズを確認します。
- 英語・韓国語では可視main領域から日本語の仮名・漢字を検出します。
  意図的な言語切替ナビは除外します。`undefined` や未展開のプレースホルダーも検出します。
- ブラウザのJavaScript例外、ローカル資材のHTTPエラー・通信失敗を各ケースで検出します。

文言は `locales-snapshot.json` と照合します。このファイルは実装時点の
`data.js` の言語別データを一度だけ固定したスナップショットであり、実行時に本体から
期待値を再生成しません。翻訳文の正しさを人間が保証したデータではありません。
Type番号の位置表はT3の固定値を継続使用します。
CSSの大文字変換があるブランド文字列は、表示上の大文字を考慮して比較します。

## 内部集計値についての証拠の区別

ブラウザテストは回答状態への代入や内部フックを使わず、実際のボタンをクリックします。
主タイプ・併記タイプ・同点候補を画面から取得して3言語比較します。

`score`、`solo`、`focus` と全9タイプの順位はHTMLに表示されません。
これらをブラウザ内から直接観測したとは主張しません。
同じ14回答セットについて、既存Unitハーネスで各言語を初期化し、実際の採点関数の
全指標・全順位・候補を共通の固定期待値と照合します。
ハーネスに追加したのは言語とHTMLパスの選択だけで、既定は従来どおり日本語です。
既存の観測フックの挿入失敗検出も維持します。

Unitの42件とブラウザの51フロー、および結果比較1件を組み合わせて証拠とします。
ブラウザ内部値の直接検査が必要な工程では、別途その観測方法を検討する必要があります。

## 配信・公開と対象外

テストサーバーは既存の日本語HTML・JS・PNGに加え、英語・韓国語HTMLだけを許可します。
テスト、Git、依存パッケージのパスは引き続き404です。
ブラウザ環境、npmキャッシュ、ログはチェックアウト外に置きます。
本番デプロイ設定、CI、コミット、プッシュ、PR、マージ、公開は実行しません。
将来の公開には別途アプリ資材だけの公開対象を確認してください。

Google Fontsへの通信はT3と同様に遮断し、ローカルのフォールバックフォントを使います。
フォント配信・字形の品質、翻訳品質全般、文字切れの目視・スクリーンショット比較、
モバイル・他ブラウザ、画像保存・共有、外部リンク先の動作は対象外です。
文字のDOM上の存在と可視性は確認しますが、すべてのグリフの描画品質は保証しません。

T4の結果を報告したところで停止し、T5には進みません。
