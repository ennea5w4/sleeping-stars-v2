# T3：日本語版の実ブラウザE2E

## 実行方法

Node.js、Chromium、Playwright coreを使います。依存パッケージ、npmキャッシュ、
ブラウザのプロファイルや生成物はチェックアウト外に配置してください。
ルートのpackage.json、lockfile、アプリのHTML/CSS/JavaScriptを変更する必要はありません。

今回検証した組合せ：Node.js v24.22.1、Playwright core 1.65.0、
システムChromium 156.0.8078.79（Linux、headless、1280×900）。

以下はリポジトリのルートで実行する例です。

```sh
npm --cache /tmp/sleeping-stars-t3-npm-cache install \
  --prefix /tmp/sleeping-stars-t3-runtime \
  --no-audit --no-fund --ignore-scripts --save-exact playwright-core@1.65.0

SS_E2E_RUNTIME=/tmp/sleeping-stars-t3-runtime \
SS_E2E_BROWSER=/usr/bin/chromium \
node --test tests/e2e/ja.test.cjs

node --test tests/scoring.test.cjs
```

既存の外部作業ディレクトリを再利用する際は、他の作業の依存関係を上書きしないようにしてください。
ブラウザがない場合は別途用意する必要があります。起動失敗はテスト失敗として扱い、SKIPやPASSに変換しません。
初回実行時はnpmへの接続が必要ですが、ブラウザテスト自体はローカルだけで実行できます。

## 実行構成と公開への影響

- `server.cjs` が127.0.0.1の空きポートにHTTPサーバーを起動し、終了時に停止します。
- 既存の `index.html`、3つのJS、PNGを無加工で配信します。T4の追加に伴い、共通サーバーは `/en/`・`/ko/` の実HTMLも許可します。
- `tests/`、`.git/`、`node_modules/`などのパスは配信しません。
- E00でアプリのJSが原本と同じこと、テスト・実行環境のパスが404になることを確認します。
- Playwrightは実HTMLに対して通常のクリックとキーボード操作を行います。回答状態の直接代入、
  採点関数の呼び出し、観測フック、アプリレスポンスの差し替えは行いません。
- 各テストで新しいブラウザコンテキストを作り、前の回答を引き継ぎません。
- 全テストでブラウザのJavaScript例外とローカルアプリ資材の読み込み失敗を検出します。
- テストレポート、スクリーンショット、トレース、ブラウザ本体をリポジトリ内に生成しません。
- Google Fontsへの通信だけを明示的に遮断し、フォールバックフォントで検証します。
  外部フォントの配信や見た目は今回の検証対象外です。その他の外部通信は失敗として扱います。

デプロイ設定や公開処理は追加・実行しません。このローカルサーバーの配信制限は、
将来の本番デプロイ設定を変更するものではありません。公開を別途行う際は、
アプリ資材だけを配信対象にし、testsや外部の実行環境を含めないことを確認してください。

## 固定期待値と検証項目

`ja-fixtures.cjs` に8問×9タイプの日本語と表示順をリテラルで固定しています。
ブラウザ内の `SS_DATA` や本体の回転計算を期待値として読み出しません。

| ID | 実ブラウザでの検証 |
| --- | --- |
| E00 | 配信するJSが原本と一致し、テスト・Git・依存パッケージのパスを配信しない |
| E01 | 全8問の未選択時にNextがdisabled。Enter操作でも先へ進まず、1語選択後は進める |
| E02 | 全8問で1〜3語選択でき、4語目は追加されない。画面の選択数と総カウンターを確認 |
| E03/E09 | Type 1〜9をそれぞれ全8問で単独選択。全72位置の表示語と最終タイプを確認（9テスト） |
| E04 | 全8問でType 1・2を選択後にType 1を解除。画面・カウンター・最終結果Type 2に反映 |
| E05 | Field 8からField 7へ戻り、保存済み回答を変更。変更前ならType 1、変更後はType 2となる固定回答で検証 |
| E06 | 結果から再スタート。全8問で旧選択がなく、カウンター・Next状態・新結果が初期化を反映 |
| E07/E08 | 2者・3者同点の候補文と順序を確認し、候補全員を個別に選択して対応する主結果を表示（計5テスト） |

E02でも3者同点からの結果遷移を確認します。結果では選択語一覧の完全一致と、
該当キャラクター画像が読み込まれることも確認します。
期待値はT1・T2で固定した現仕様に基づき、既存の採点処理を変更しません。
